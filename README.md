# 🔮 校园赛博玄学 · 今日晨间运势

> 一个无需后端、无需构建、打开即用的赛博朋克风多页占卜 Web 应用。  
> 手动录入今日课程与昨晚状态，生成晨间运势、自动补给与期末渡劫概率。

---

## 项目简介

本项目是一个纯前端单文件应用，围绕「今日课程 × 昨晚睡眠 × 期末考试」构建了一套本地规则引擎。  
用户在第一页手动录入课程时间线与昨晚状态，随后依次经过启动舱、量子演算、赛博播报，并在隐藏的期末渡劫页中重新录入考试科目、设置难度、抽签并生成符咒。

项目适合作为：

- 前端 HTML / CSS / JavaScript 综合练习
- 赛博朋克视觉与交互演示
- 课程设计、社团展示或趣味答辩项目
- 无后端、零安装的静态网页部署示例

> ⚠️ 本项目仅用于娱乐与展示，所有运势、概率、补给和符咒均由本地模拟规则生成，不构成任何学习、饮食、医疗或考试建议。

## 页面与功能

| 页面 | 路由 | 功能 |
| --- | --- | --- |
| 01 / 输入页 | `#input` | 手动录入今日课程、上课时间、课程难度、考试标记；选择昨晚睡眠 / 精神状态。 |
| 02 / 启动舱 | `#launch` | 展示今日数据摘要，确认后点火进入演算。 |
| 03 / 量子演算 | `#calc` | 模拟终端启动日志、进度条与 AI 推演过程。 |
| 04 / 赛博播报 | `#result` | 展示今日人设、运势值、宜 / 不宜、自动补给、证据链、分时段提示、行动指南和开运参数。 |
| 05 / 期末渡劫 | `#exam` | 独立录入考试科目与难度，计算过关 / 挂科概率，抽签、叠加 Buff、生成赛博符咒。 |

> 初次打开 `#calc` / `#result` 时，路由守卫会把没有今日会话的访问送回 `#input`；正常流程应从第一页开始，或通过启动页重新占卜。

### 核心特性

- **纯前端、单文件**：所有 HTML、CSS、JavaScript 均内联在 `index.html` 中。
- **手动录入课程**：第一页只保留手动输入，不再包含 CSV / JSON 文件上传模块。
- **自动生成今日补给**：不再手动填写「今日补给」，由占卜结果自动推导适合 / 不适合的食物、饮品和补给时机。
- **独立考试科目**：第 5 页可重新录入考试科目，并逐项选择简单 / 中等 / 困难 / 地狱级难度。
- **数据变更防误读**：修改输入后旧结果会进入 `STALE` 状态，需要重新占卜才会刷新。
- **响应式赛博视觉**：深色霓虹、扫描线、网格、终端日志、仪表盘、签筒和符咒动画。
- **无持久化**：所有数据保存在浏览器内存中，刷新页面后回到初始状态。

## 技术栈与目录结构

### 技术栈

- **HTML5**：语义化多页面结构、表单与无障碍属性。
- **CSS3**：自定义赛博朋克样式、网格背景、扫描线、`conic-gradient` 仪表盘与关键帧动画。
- **原生 JavaScript（ES6+）**：页面路由、状态管理、规则引擎、DOM 渲染、抽签与符咒生成。
- **Tailwind CSS Play CDN**：通过 CDN 提供原子化样式类，无需本地构建。
- **浏览器 History API / Hash 路由**：在 `#input`、`#launch`、`#calc`、`#result`、`#exam` 之间切换。

### 目录结构

```text
cyber-divination/
├── index.html      # 页面结构、样式、脚本与全部模拟数据
└── README.md       # 项目说明与复现指南
```

> 本项目没有 `package.json`、`package-lock.json`、`node_modules`、构建产物或后端服务。  
> 评审时只需要关注 `index.html` 这一个运行文件。

### 4. 启动项目

#### 方案 A：直接打开（30 秒，最快）

1. 找到项目根目录下的 `index.html`。
2. 双击文件，或右键选择「打开方式 → Chrome / Edge」。
3. 地址栏会显示类似：

```text
file:///D:/cyber-divination/index.html
```

说明：

- 本项目没有模块导入、跨域请求或后端接口，因此可以直接用 `file://` 打开。
- 代码已对 `file://` 下 History API 的限制做降级处理，路由会退回 hash 导航。
- 如果浏览器控制台出现 `file://` 相关提示，但不影响使用，可忽略；更推荐下面的静态服务器方式。

#### 方案 B：Python 静态服务器（推荐）

Windows PowerShell：

```powershell
cd D:\cyber-divination
py -m http.server 8000
```

如果 `py` 不可用，改用：

```powershell
python -m http.server 8000
```

macOS / Linux：

```bash
cd /path/to/cyber-divination
python3 -m http.server 8000
```

启动后打开：

```text
http://localhost:8000/
```

停止服务器：在终端按 `Ctrl + C`。

#### 方案 C：Node.js 静态服务器（可选）

要求 Node.js 18+。项目本身没有 npm 依赖，`npx` 只用于临时启动静态服务器。

```powershell
cd D:\cyber-divination
npx --yes serve . -l 8000
```

或使用不缓存模式：

```powershell
npx --yes http-server . -p 8000 -c-1
```

打开：

```text
http://localhost:8000/
```

> 不需要先执行 `npm install`。如果 `npx` 首次运行提示下载包，按提示允许即可。

#### 方案 D：VS Code Live Server（适合演示）

1. 在 VS Code 扩展市场安装 **Live Server**（作者：Ritwick Dey）。
2. 在资源管理器中右键 `index.html`。
3. 选择 **Open with Live Server**。
4. 浏览器会自动打开，通常地址为：

```text
http://127.0.0.1:5500/index.html
```

#### 启动后的自检

打开浏览器开发者工具（`F12`），确认：

- Console 没有红色报错。
- Network 中 `cdn.tailwindcss.com` 返回成功。

### 5. 部署到静态托管平台

本项目是单文件静态站点，**构建命令为空，输出目录为项目根目录**。

#### GitHub Pages

1. 将 `index.html` 和 `README.md` 推送到 GitHub 仓库的 `main` 分支。
2. 打开仓库 **Settings → Pages**。
3. **Build and deployment → Source** 选择 **Deploy from a branch**。
4. 分支选择 `main`，目录选择 `/ (root)`，点击 **Save**。
5. 等待部署完成后访问：

```text
https://<你的用户名>.github.io/<仓库名>/
```

如果仓库名是 `<你的用户名>.github.io`，访问地址为：

```text
https://<你的用户名>.github.io/
```

#### Netlify

1. 打开 [Netlify Drop](https://app.netlify.com/drop)。
2. 将整个项目文件夹拖入页面。
3. 不需要设置 Build command，Publish directory 保持项目根目录。
4. 部署完成后使用 Netlify 提供的 HTTPS 地址访问。

#### Vercel

1. 在 Vercel 控制台导入 GitHub 仓库。
2. Framework Preset 选择 **Other**。
3. Build Command 留空。
4. Output Directory 填写 `.`。
5. 点击 Deploy，等待生成的 HTTPS 域名。

#### 自有服务器（Nginx 示例）

将 `index.html` 放到静态目录，例如 `/var/www/cyber-divination/index.html`：

```nginx
server {
    listen 80;
    server_name your-domain.example.com;

    root /var/www/cyber-divination;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

> 页面使用 hash 路由，不依赖服务端重写规则；上面的 `try_files` 主要用于根路径访问。

## 使用说明

### 第一页：今日数据录入

1. 在「今日课表 / 手动录入」中填写课程名、开始/结束时间、难度和考试标记。
2. 点击「录入今日课程」加入课程档案，可多次添加。
3. 在「昨晚状态 / 手动输入」中选择一项睡眠 / 精神状态。
4. 点击「进入启动页」进入下一页。

### 第二页：启动舱

- 展示当前已接入的数据摘要。
- 点击「开始占卜 · 今日运势」后进入演算流程。
- 点击「返回修改今日输入」可回到第一页。

### 第三页：量子连线演算

- 模拟终端启动日志、量子链路进度与 AI 推演。
- 演算完成后自动跳转到播报页。
- 若页面被中途刷新，会回到输入页，需要重新录入数据。

### 第四页：今日赛博播报

- 今日赛博人设与运势值。
- 今日宜 / 不宜、核心注意事项。
- 自动生成的今日补给（适合吃 / 不适合吃 / 饮品 / 时机）。
- 今日赛博证据链、课程时间线分时段提示。
- 今日渡劫指南、开运参数与免责声明。
- 可点击「重算今日」重新随机生成当日结果。

### 第五页：期末渡劫

- 通过第一页标题栏右侧的「开启期末渡劫通道」进入。
- 可独立录入考试科目，并逐项设置难度。
- 支持从今日课表带入、清空考试科目、修改难度、删除科目。
- 提供过关概率、签筒、Buff 与赛博符咒。
- 点击「返回输入页」退出期末暗线。

## 常见问题

### Q1：打开后页面没有样式，只有文字和按钮？

通常是 Tailwind CDN 没有加载成功。请检查：

```text
https://cdn.tailwindcss.com
```

是否可以在浏览器中直接访问。若网络受限，请切换网络或使用可访问 CDN 的环境。

### Q2：双击 `index.html` 可以运行吗？

可以。项目是单文件、无模块导入、无接口请求的纯前端页面。  
但部分浏览器对 `file://` 下的 History API 有限制，代码会降级为 hash 路由。为避免浏览器差异，**推荐使用静态服务器**：

```powershell
py -m http.server 8000
```

### Q3：`python` 命令打开了 Microsoft Store 怎么办？

这是 Windows 的 Python 别名问题。改用：

```powershell
py -m http.server 8000
```

或安装 Python 后重新打开终端。

### Q4：端口 8000 被占用怎么办？

换一个端口，例如 8080：

```powershell
py -m http.server 8080
```

然后访问：

```text
http://localhost:8080/
```

Windows 下可查看占用：

```powershell
netstat -ano | findstr :8000
```

### Q5：为什么刷新后数据都没了？

本项目没有使用 `localStorage`、`sessionStorage` 或后端数据库，所有课程、睡眠、考试科目、签文和符咒都只保存在当前页面内存中。刷新页面会回到干净初始状态，这是预期行为。

### Q6：为什么期末页找不到？

期末渡劫页是隐藏暗线，不在普通步骤条中直接展示。请在第一页标题栏右侧点击 **开启期末渡劫通道**。

### Q7：为什么修改昨晚状态后不能抽签？

在已经生成今日运势后修改输入，旧的今日结果会进入 `STALE` 状态，工程上会冻结旧概率，避免用户拿过期数据继续抽签。请回到启动页重新点击「开始占卜 / 重算今日运势」，清除 `STALE` 后再抽签。

### Q8：控制台出现 Tailwind CDN 警告怎么办？

`cdn.tailwindcss.com` 的 Play CDN 面向原型和演示，控制台可能提示不建议用于生产环境。本项目用于课程展示，保留 CDN 可以保证零安装复现；若用于正式生产，建议改为本地 Tailwind 构建产物。

### Q9：可以在手机上演示吗？

可以。页面使用响应式布局；手机与电脑处于同一局域网时，可让静态服务器监听所有网卡：

```powershell
py -m http.server 8000 --bind 0.0.0.0
```

然后用 `ipconfig` 查看电脑的局域网 IP，在手机浏览器访问：

```text
http://<电脑局域网 IP>:8000/
```

注意 Windows 防火墙需要允许 Python 或对应端口。也可以直接部署到 GitHub Pages / Netlify 等平台，用手机访问线上地址。
